# MegaPrint

## Overview

MegaPrint is a business website and management platform developed for a printing services company. The project combines a public-facing website with an administrative system for managing products, services, testimonials, and customer interactions.

## Key Features

* Product catalog
* Portfolio of completed work
* Customer testimonials
* Contact management
* Administrative dashboard
* REST API integration

## Technologies

### Backend

* Laravel 11
* PHP
* MySQL

### Frontend

* HTML5

* JavaScript

### Infrastructure
